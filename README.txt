CS_PROJECT_2026_-HARDWARE-MONITOR-

Description: 

-A python application made to monitor the live performance and return the information of #several hardware components in a computer.

Features:

- CPU monitoring 
- RAM monitoring 
- Storage monitoring 
- Hardware information 
- Performance graphs of hardware components 
- Warning indications when the performance of a specific component is worse than the minimum requirements to function

Technologies: 
- Python 
- Tkinter 
- psutil 
- Matplotlib

Usage:

1- Open the "dist" file in Trace file
2- Open the "Trace" executable

Requirements:

-Windows
