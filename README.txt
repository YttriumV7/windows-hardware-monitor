CS_PROJECT_2026_-HARDWARE-MONITOR-

Description: 

-A python application made to monitor the live performance and return the information for the main hardware in a computer.

Features:

- CPU monitoring 
- RAM monitoring 
- Storage monitoring 
- Hardware information 
- Performance graphs of hardware components 
- Colour indications when the performance of a component is worse than the optimal performance

Technologies: 
- Python 
- SQL
- tkinter 
- psutil 
- matplotlib
- DB Browser

What I learned:
- GUI development
- System information collection
- Debugging
- Working with Python libraries
